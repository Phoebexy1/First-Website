# My First Website

This was my first web development project, created in 2022 when I started learning how to code.

## About the Project

A simple webpage created using HTML and CSS. The page features a navigation bar, contact links, and a large hero image.

## What I Learned

This project helped me practice the basics of:

- Creating a webpage structure
- Building a navigation bar
- Adding images to a webpage
- Styling elements with CSS
- Working with links

## Note

This project represents the beginning of my front-end development journey in 2022.
